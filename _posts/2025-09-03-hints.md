## Копи паста текстов

В форматах и прочем мультикаде (кроме таблиц)

При редактировании на чертеже, невозможно выполнить `Ctrl+A.. C...V...X`, \
клавиатурные сокращения применяются не к выделенному тексту, а всему чертежу \
`ПКМ` настроена на завершение редактирования на чертеже \
Но на клавиатуре есть волшебная кнопка вызова контекстного меню,

## Копировать свойства наоборот 

- выбрать объекты
- команда `ККС`
- указать объект с которого брать свойства

```lisp
(defun c:ккс (/ ss);;Копировать свойства на объекты 
    (if (setq ss (ssget))
        (command "_.matchprop" pause ss "")
    ) ;_endif
    (princ)
) ;_enddefun
```

## Отзеркалить и удалить оригинал

```lisp
(defun c:зд ();;зеркалить и удалить оригинал
    (command "_Mirror" "_p" " " pause pause "д")
    (command "select13"); выбираем новый объект
    (princ)
) ;_enddefun
```

## Закрыть без сохранения

```lisp
(defun C:збс ()
    (command "close" "Y")
(princ)
)
```
