## Копи паста текстов

В форматах и прочем мультикаде (кроме таблиц)

Редактирование на чертеже, невозможно Ctrl+A.. C...V...X применяются не к выделенному тексту, а всему чертежу \
Но на клавиатуре есть кнопка контекстного меню, ей можно вызвать меню, там все это есть

![Use-a-Right-Click-Shortcut-Key-1](Use-a-Right-Click-Shortcut-Key-1.png)

и все эти команды доступны

![contecst-menu](contecst-menu.png)

## Копировать свойства наоборот 

- выбрать объекты
- команда `ККС`
- указать объект с которого брать свойства

```lisp
(defun c:ккс (/ ss);;название команды может быть любым
    (if (setq ss (ssget))
        (command "_.matchprop" pause ss "")
    ) ;_endif
    (princ)
) ;_enddefun
```

## Отзеркалить и удалить оригинал

```lisp
(defun c:зд ();;зеркалить и удалить оригинал
    (command "_Mirror" "_p" " " pause pause "д")
    (command "select13")
    (princ)
) ;_enddefun
```

## закрыть без сохранения, без архива

```lisp
(defun C:збс ()
    (command "close" "Y")
(princ)
)
```

## проверить документ

```lisp
(defun C:ппр ()
    (command "ПРОВЕРИТЬ" "д" "н")
)
```
