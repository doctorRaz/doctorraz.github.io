# Добавление программ в автозагрузку CAD

Добавление в автозагрузку рассмотрим на примере добавления в автозагрузку [PlotSPDS.NET для nanoCAD](/download/Release.NET_NC23-26_2025.12.05(2.1.9470).zip)

[Пример записи данных в атрибуты блоков](/download/repwrite/repwrite.zip)

**Загрузка программы**
1.     Скачать архивчик (в аттаче)
2.     Если установлена предыдущая версия **PublishNC AnyCpu** - надо удалить его из автозагрузки
3.     Распаковать zip-архив с программой;
4.     Папку **PlotSPDS_for_nanoCAD** поместить в любой каталог, куда у пользователя есть доступ;
5.     Добавить файл **PlotSPDS_22.package** (для nanoCAD22-24, для nanoCAD20- **PlotSPDS_20.package**) в автозагрузку, как показано на скриншоте.
1.     Перезапустить nanoCAD.
2.     На ленте появится вкладка “drzTools” с панелью Публикация СПДС.
1.     В классическом интерфейсе появится новый пункт меню и панель инструментов1.     Eсли  панель инструментов не появилась вызвать ее можно по ПКМ на свободном месте панели инструментов
